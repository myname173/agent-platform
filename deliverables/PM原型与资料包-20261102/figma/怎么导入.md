# 怎么把这些 SVG 放进 Figma

## 一次拖入（你现在一个文件都不用先建）

新增了一张合板：**`00-合板-全部画板-一次拖入.svg`**（6260×1860，内含 8 个 `Board/*` 顶层组）。

1. Figma 里 **Ctrl+N** 新建空白 Design 文件。
2. 把 `00-合板-全部画板-一次拖入.svg` 从资源管理器**拖到画布上**（或 **Ctrl+I / Place image** 选它）。松手即全部进来。
3. 想单张导入也行：`01…08.svg` 每张尺寸已固定（1440×900 六张、1600×900 两张）。

> 首页/草稿列表里直接拖，Figma 通常会自动建一个 untitled file —— 这条我没在你的机器上验过，以实际为准；`Ctrl+N` 再拖是稳的路径。

## 导入后建议做的三件事

1. 每个 `Board/*`（或单张顶层组）选中后右键 **Frame selection**（Windows **Ctrl+Alt+G**）转成 Frame，即成标准画板，可以加分页与自动布局。
2. 文本图层按 Geist / Geist Mono 命名，装了字体自动对上；没装会回落 Segoe UI / 微软雅黑，可批量改。
3. 组件化：`Card/*`、`KPI/*`、`Badge/*`、`Button/*` 逐个提为 Component，命名与控制台里的 shadcn 组件对齐。

层级结构（我用结构检验过：合板共 147 个命名组、622 个文本图层、312 个矩形）：
`Board/<文件名>` → `Frame/…` → `Card/最近告警`、`KPI/错误率`、`Table/…`、`Button/立即自检`、`Badge/已触达`、`FlowArrow`。

## 颜色不要手改

`01–05` 用 `vercel.css` 的浅色值，`02` 用 `operations-dashboard.tsx:40-49` 的暗色常量，`06` 用 `pivot-theme-v2.css` 的 v2 绿系（**不是 README 里旧的蓝青**），`07` 用 Telegram 客户端色。

## 重新生成

```bash
node deliverables/PM原型与资料包-20261102/make-figma-svgs.mjs   # 重画 8 张 + 自动合成 1 张合板
node deliverables/PM原型与资料包-20261102/_verify/lint-svg.mjs . # 结构 + 布局体检（越界/Card 重叠会 FAIL）
```

`_verify/_control/` 里放了两个**故意做坏**的对照 SVG，用来证明这道门真的会失败：

```bash
node deliverables/PM原型与资料包-20261102/_verify/lint-svg.mjs _verify/_control   # 预期 EXIT=1
```

## 为什么不是 Figma 里直接画出来的

Qoder 装的官方 Figma 连接器只暴露 26 个工具，全部是读文件 / 读节点 / 渲染图 / 评论 / dev resource 这一类，**没有任何写画布的接口**。所以"AI 在 Figma 里画原型"这条路现在走不通，我用可导入的分层 SVG 代替，并且这个替代是**生成式的**：改一处基元，8 张画板一起变，比手拖更贴近代码。
