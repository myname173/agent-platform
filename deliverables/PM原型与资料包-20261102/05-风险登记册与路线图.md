### v2 · 把能力补完

- 知识库**异步摄取**开开关（`PLATFORM_KB_ASYNC_ENABLED` 当前默认 `false`）+ `platform-worker`（`phase2` profile）转常态。退出条件：100 篇批量摄取期间前台检索不阻塞、`task_id` 全程可查。
- MCP `tools/list` ↔ L2 注册表打通（对外与对话看到同一份工具面）。
- 记忆**双向同步**（当前 TG 可读 LobeHub 记忆，LobeHub 不读平台库）。
- 发票 / 报销：图片 → 结构化记账（需要新增带图片入参的侧工具）。
- 团队视图周报落地到多人：前提是先把"多人日常使用"真正跑起来 —— 现在不假装。

### v3 · 出公网与多活的前置

- 公网暴露前必须就位：TLS + OAuth（当前 MCP 仅局域网）、密钥独立吊销、限速与审计的告警化。
- Prometheus 常态 + 明确 SLO（业务指标**继续不进** Prometheus，避免与 Console 两套总量）。
- 备份**恢复演练**自动化：投掷库还原 + 还原后跑 48 项自检（现在已有演练，纳入常态门禁）。
- 事件总线 / outbox（`event-bus` profile + Kafka）——只有在多机部署下才启动，单节点受控模式不给它写功劳。

### 明确不做（同样写进路线图，防止被"顺手加一下"）

- 控制台可写阈值/密钥（D8）；模型建改删工作流（D10）；把 `ta 我收到了` 做成"完成"（语义红线）；多租户与计费。
