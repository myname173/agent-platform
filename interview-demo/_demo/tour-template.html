能力 ① · 私域知识

先查知识库，答案带出处

混合检索 → 重排 → CRAG-lite 评分；命中即引用 [来源: 文档名]，不瞎编。

能力 ① · 检索质量

检索演练：排序一眼可见

同一查询实时召回 Top-K 并打分：相关块 92%，无关块 ≤21%，分离清晰。

能力 ② · 上网核实

知识库没有，就自己上网搜

并行多次 web_search；开口先声明局限（只看标题摘要、版本待核实）。

能力 ② · 来源与诚实

每条结论标 [来源:web]

只取多篇互相印证的部分；低质站点与过时风险主动说明，不装确定。

能力 ③ · 办事

一句话，落成待办 + 提醒

并行调 todo_add + create_reminder；按指派人时区算时间，落库可追溯。

能力 ④ · 协作

按人、按项目组织活儿

成员各有时区与通道，议程按人推送；待办/文档按项目归集。

可观测

一次对话 = 一条跨服务 trace

OTel 串起 bridge → 网关 → 工作流节点：51 spans，限流/上游/回落逐段可见。

运营

对话量 / 错误率 / 延迟 / 成本，一屏

Overview 汇总真实流量指标与今日待办、委派，运营不用翻日志。

运营 · 控制面

工作流 / 告警 / 模型 / 密钥

工作流源码可视化、告警自愈、模型可换、密钥分级管理。

运营 · 知识与内容

摄取 / 文档 / 简报 / 订阅

知识入库→分块→嵌入；doc-forge 出文档；简报与主题盯梢定时产出。

边界与安全

沙箱准入 · 限流 · 审计 · 保留期

Python 沙箱共享密钥 + 请求级准入；runtime 限流/幂等；操作写审计；数据按保留期清理。

Summary

它把 Agent 做成了可运营的产品

  • 会查：混合检索 + 重排 + CRAG-lite，答案带出处。
  • 会搜：web_search 并行核实，标来源、承认不确定。
  • 会办：16 工具并行调用，按人时区落库。
  • 可见：跨服务 trace + 运营指标 + 告警自愈。
  • 可控：沙箱准入、限流、审计、保留期、密钥分级。

口径：截图来自一次性隔离演示栈（opt-in 全开），非现网默认配置；检索增益为冻结语料离线实测，现网答案质量增益未验。演示栈可 down -v 一键回滚，零碰现网。
