### 踩到的坑（重要）
1. **给 IF 节点加分支时，main[0] 是 true 分支、main[1] 是 false 分支。** 我一开始把 sweep 挂到 main[0]（错误分支），导致手动 run 时它从不执行——而每分钟的定时 tick 又会执行，所以现象是「偶发有效」，极易误判成竞态。
2. **并行分支与 respondToWebhook 有竞态**：手动 run 的响应会在并行分支完成前返回，立刻读数据库会读到旧值。验证时必须 sleep 若干秒再读。
3. 验证「不静默丢弃」这类安全属性，最有效的办法是**部署前抓基线、部署后逐字比对**，而不是只看新功能是否 work。
