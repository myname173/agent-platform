# Runtime baseline

This is a local Docker Desktop baseline, not a capacity claim. The test ran
inside the `platform-runtime` container and did not call an upstream model or
write business rows.

Configuration:

- 200 idempotency admissions, concurrency 50
- 100 rate-limit calls, limit 50 per 60-second window
- 200 lock acquisitions against one resource, concurrency 50

| Operation | p50 | p95 | max | Result |
| --- | ---: | ---: | ---: | --- |
| Idempotency admission | 46.86 ms | 120.29 ms | 135.74 ms | 1 admitted, 199 in-flight/replayed |
| Rate limit | 34.42 ms | 44.08 ms | 45.79 ms | 50 allowed, 50 blocked |
| Lock acquisition | 31.48 ms | 49.20 ms | 51.45 ms | 1 acquired, 199 contended |

Repeat with:

```powershell
docker compose exec -T platform-runtime npm run test:load
```
